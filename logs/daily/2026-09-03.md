  assets layer served any existing file before the Worker ran. Pinned
  `wranglerVersion: "4.81.0"` in deploy.yml. Verified after: every old
  file URL 410, all 4 live pages 200, `/j` 302 to gates, key file 200.

## What was observed

  URL that exists on disk, not just a made-up one.

## Learning
Cloudflare Workers Assets is two layers: static asset serving and the
Worker. Without an honored `run_worker_first`, any file that exists on
disk wins and the Worker never sees the request. The wrangler that
deploys decides whether the field is honored, so the CI version matters
as much as the config. Pin it.
