The placeholder in the HTML said 2,125 until I worked out the default by
hand: 5,000/5 = 1,000, which triggers the 1,000-level bonus (+1,000), so the
answer is 2,000. The guard now pins the placeholder to the function. The same
kind of bug could sit in other calculators' static defaults, and nothing
checks them.

## Learned
- Caesars' benefits grid parses cleanly from the raw HTML via
  `firecrawl --format rawHtml`. Each benefit is a `CETTRBenefit` with six
  `benefit-value` cells. An empty cell is either `benefit-empty` or a
  completely empty div (the Seven Stars upgrade row has one). Count the divs,
  not the markers.
- Bing `GetPageQueryStats(page=...)` gives the per-page query list. Use it
  before retitling to see what a title change could cost.
- The GSC homepage `referringUrls` list is spam. Don't mistake it for links.
