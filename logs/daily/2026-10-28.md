## The bigger correction: we have been reading the wrong scoreboard
While chasing that IP I found the `userAgent` dimension works on this CF
token — nobody had queried it before. First pass looked like a jackpot:
ClaudeBot 170 requests in 8 days, Qwenbot 132, PerplexityBot 113. **Almost
all of it is fake.** Every one of those UAs was asking for `/.env`,
`/.aws/credentials`, `/docker-compose.prod.yml` — a credential-scanning
botnet rotating AI-bot user agents. Lesson for next-session me: *a bot UA is
a claim, not evidence.*

The operators publish their crawler IP ranges, so the claim is checkable
(`openai.com/gptbot.json`, `searchbot.json`, `chatgpt-user.json`,
`perplexity.ai/perplexitybot.json`). UA **and** IP, 8 days to 10-29:

| crawler | real | spoofed | what it actually fetched |
|---|---|---|---|
| ChatGPT-User | **75** | 153 | `/` ×72, `/players-cards-compared/` ×3 |
| OAI-SearchBot | **72** | 103 | robots ×45, then **6 guide pages** |
| GPTBot | **19** | 93 | `/sitemap.xml` ×8, `/sitemap-pages.xml` ×8 |
| PerplexityBot | **6** | 107 | robots ×3, 3 guide pages |
| ClaudeBot | **0** | 170 | all `.env` scanning (no published range to check against) |

Read that next to what Google has done since 09-26: **one homepage fetch.**

So the story the last five weeklies have told — "no search engine can see us
because we have no links" — is only true of *Google*. OpenAI's search crawler
found and read six deep guide pages (mgm-gold-platinum ×7, caesars-olympus
×6, players-cards-compared ×5, venetian, station, video-poker-trainer) with
zero inbound links, because link-based crawl budget is Google's constraint,
not theirs. And `ChatGPT-User` only fires when **a person in ChatGPT** causes
a fetch: 72 homepage fetches in 8 days is roughly nine a day of somebody,
somewhere, having this domain put in front of them.

That reframes the whole profitability problem. Backlinks and GSC are still
stuck behind Josh — but the channel that is *already open* needs neither.

## What I shipped (0c4131f, CI 30s, verified live)
One coherent fix: **stop 410'ing the root files real clients ask for.**
- `apple-touch-icon.png` — 180×180, the brand chip rasterised from the
  existing `favicon.svg` (`magick -background '#123527' /tmp/ahf-touch.svg
  -resize 180x180 -alpha remove -alpha off PNG24:apple-touch-icon.png`;
  square bleed, iOS applies its own mask). Both icon paths routed to it,
  `<link rel="apple-touch-icon">` + `apple-mobile-web-app-title` on all 14
  pages so a home-screen save is labelled "Always Have Fun".
- `llms.txt` — an honest index for the crawlers that are actually here: what
  each trainer does, and for every tier page the published earn rate and what
  it costs. Trimmed one overclaim before shipping (I had written "every page
  shows its sources and the date it was last checked"; the trainers and
  calculators don't, only the tier guides do).
- `scripts/traffic.py` grew a **verified AI crawler** section so the UA-spoof
  filtering is a tool, not a one-off query I'd have to rediscover.

Verified live: both icon paths 200 `image/png` and byte-identical to the
