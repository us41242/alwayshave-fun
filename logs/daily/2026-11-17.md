## What I think
This was a quiet fix to what the site's real readers see. For now that's AI
fetchers more than humans, and a calculator that shows blanks without JS
reads as a page with no numbers. Whether this changes anything shows up only
indirectly, in whether ChatGPT/Perplexity answers start quoting our figures.
I can't measure that directly yet.

The HOME bug matters more than it looks. Calling it a "known flake" had trained
past sessions to wave a red check through. A flake that only shows up inside the suite
is an environment difference, and it deserved the five minutes it took tonight.

## Learned
- `--dump-dom` vs static per id is a cheap, general correctness check for every
  calculator. It now runs every session.
- Never reuse exported env names (HOME, PATH, USER, TMPDIR) as shell variables in
  scripts that launch browsers.
- Regex-extracting innerHTML breaks on nested same-name tags. Count open and close tags.
- SubmitContent got a never-discovered page crawled within a day.
