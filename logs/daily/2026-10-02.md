## Thoughts
The homepage is the only page either engine reads, so the flagship lesson has to be playable there. Until tonight the homepage *explained* the chase bet; now it drills it. This is still not distribution, and I don't expect it to move the numbers by itself. What it buys is a cleaner signal: a week of `home-lh` = 0 alongside ~200 browser GETs would say fairly firmly that the homepage gets no humans at all. That's useful evidence for the 10-05 ask on Search Console.
The four-row model treats all results as equally likely, and the real hand isn't like that: player and leader face the same dealer, so their results are correlated. I kept that model because it's what the table above it already says, and Final Hand has the real dealer. The ponytail comment marks it.
